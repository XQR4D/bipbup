## 📈 Метрики
Проект отслеживает посещаемость и взаимодействие через Яндекс Метрику, сохраняет динамические данные в cookie файлы, обращается от имени пользователя на API запрос. Все метрики прописаны в соглашении которое принимает пользователь входя на сайт (баннер).
